# proyecto_inv_cl

Dashboard personal de finanzas e inversiones (PWA, costo cero). Consolida Mercado Pago, Binance, MetaMask y Balanz.

## Correr en local

```bash
npm install
npm run dev
```

Abrir http://localhost:3000 — health check en http://localhost:3000/api/health
